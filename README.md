# Pariksha – Online Assessment & Interview Platform

Pariksha is a full-stack online assessment and technical interview platform designed to streamline the recruitment and evaluation process. The platform enables administrators to create assessments, manage questions, schedule interviews, conduct live coding sessions, and track candidate performance through an interactive dashboard.

---

## Features

### Authentication & Authorization
- Secure JWT-based Authentication
- Role-Based Access Control (Admin & Student)
- Protected Routes
- User Registration and Login

### Assessment Management
- Create and Manage Assessments
- Add and Manage Questions
- Assessment Submission System
- Automatic Score Calculation
- Student Result Tracking

### Interview Module
- Schedule Technical Interviews
- Interview Management Dashboard
- Candidate Tracking
- Real-Time Interview Monitoring

### Live Coding Environment
- Integrated Coding Interface
- Real-Time Technical Assessment
- Coding Round Support
- Code Submission Functionality

### Video Interview System
- WebRTC-Based Video Calling
- Real-Time Audio & Video Communication
- Interviewer and Candidate Interaction

### Dashboard & Analytics
- Assessment Statistics
- Student Performance Analytics
- Detailed Result Reports
- Upcoming Interviews Overview
- Recent Activities Tracking

### User Management
- Profile Management
- Candidate Progress Tracking
- Performance Monitoring

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/kartik100-svg/pariksha-main.git
cd pariksha-main
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Frontend will run on:

```text
http://localhost:5173
```
