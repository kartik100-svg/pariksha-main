# Pariksha Frontend

Pariksha is an online assessment and interview platform frontend built with React. It provides user authentication, dashboards, assessment management, student results, profile management, and interview scheduling UI.

## Features

- User Login and Registration
- Protected Dashboard
- Role-based UI
- Create Assessment
- Add Questions
- View Student Results
- Schedule Interview
- Profile Page
- Responsive UI

## Tech Stack

- React.js
- Vite
- CSS
- Axios
- React Router
